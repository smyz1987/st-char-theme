# st-char-theme — 角色卡 ↔ UI主题 绑定

SillyTavern 扩展：把**酒馆 UI 主题**绑定到**单个角色卡**。

- 进入该角色的聊天时，自动切换成绑定主题
- 在聊天里可以手动换其他主题（不受影响）
- 离开该角色 / 切到其他角色时，恢复进入前的主题
- **绑定保留**，但"进入自动切换"可**单独关闭**（每个角色独立开关）

## 安装

SillyTavern → 扩展 → 安装扩展 → 输入仓库地址：

```
https://github.com/smyz1987/st-char-theme
```

## 使用

1. 打开某张角色卡的**编辑弹窗**（标题栏右侧会出现一颗**莫兰迪粉色小桃子**按钮）
2. 点桃子 → 面板列出所有可用主题 → 点一个主题即绑定（点选后立即应用该主题，可马上看到效果）
3. 面板里可以：
   - **专属美化自动匹配**：主题名与角色名重叠的主题会自动置顶并标红"专属"，省去手动逐个找匹配；匹配不到则维持手动绑定
   - 顶部搜索框：输入关键词实时过滤主题
   - 取消勾选"进入该角色时自动切换"（绑定保留，只是不自动切）
   - 点"解除绑定"清除该角色的绑定
4. 之后每次进入该角色聊天，自动应用绑定主题；切走时恢复原主题

## 说明

- 绑定以**头像文件**为标识：更换角色头像后需重新绑定一次
- 恢复基准：离开绑定角色时，恢复到"进入该角色前使用的主题"（含编辑面板里绑定时的主题）；若你在此期间手动切换过主题，则以最后一次手动选择的主题为准
- 打开绑定面板时，已绑定的主题行会自动滚动到可见位置
